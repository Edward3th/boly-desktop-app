# ParamsCatcher (legacy)

The per-engine heartbeat scripts the dev kit shipped before the Boly SDK.
Kept only as a reference for games already built with them.

**New games must use the Boly SDK** (the kit's `sdk/` folder, source of truth in
the `boly-sdk` repo). The SDK implements the same heartbeat contract and adds the
session data LumenAI needs; these scripts are no longer included in the kit.
